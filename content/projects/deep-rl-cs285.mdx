I learned deep RL in two passes. First I worked through [Berkeley's CS 285](https://rail.eecs.berkeley.edu/deeprlcourse/) on my own and built each algorithm from the paper up. Then CMU's **16-831 Introduction to Robot Learning** turned the same methods into graded experiments: searches, ablations and written analysis.

## Experiment infrastructure

Most of the work was running many experiments and trusting the results.

- **Parallel runs on shared hardware.** Launcher scripts started whole sweeps at once, one process and one CPU thread per run. A 9-run HalfCheetah search finished in about 21 minutes.
- **Tracking.** The policy-gradient runs logged to Weights & Biases, grouped by experiment. Summary scripts rebuilt every table and figure in the reports straight from the run logs.
- **Reproducibility.** Runs are defined by version-controlled launch scripts or YAML configs, with fixed seeds. As a check, I ran one HalfCheetah configuration twice. The second run matched the first exactly.
- **Tests before experiments.** Unit tests checked the advantage estimates against their known special cases before any sweep ran.

## 1. Imitation learning

<Course>CMU 16-831 · HW1 (also CS 285 HW1)</Course>

Behavior cloning trains a policy on expert demonstrations. Once the policy acts, it visits states the expert never showed it, and small errors compound. DAgger fixes this by asking the expert to label the states the policy actually visits.

<Clip
  src="/projects/rl/dagger-ant-humanoid.png"
  alt="DAgger learning curves on Ant and Humanoid, with expert and behavior-cloning reference lines."
  caption="DAgger over 10 iterations. Ant climbs from 3,502 to 4,766 and matches the 4,752 expert. Plain behavior cloning reached 3,316. Humanoid barely moves, from 305 to 366 against a 9,639 expert."
/>

The Humanoid result needed explaining. If drift were the problem, DAgger should have helped. So I swept 20 network sizes.

<Clip
  src="/projects/rl/bc-capacity-sweep.png"
  alt="Behavior-cloning return on Humanoid for 20 network depth and width combinations."
  caption="Behavior cloning on Humanoid across 20 network sizes. With only 2 expert demonstrations, bigger networks did worse. The limit was data, not drift."
/>

**Paper: ACT** (Zhao et al., RSS 2023). ACT learns two-armed manipulation from human demonstrations. It fights the same compounding errors by predicting a short chunk of actions at once and re-planning every step.

## 2. Policy gradients

<Course>CMU 16-831 · HW2 (also CS 285 HW2)</Course>

Policy gradients are unbiased but very noisy. Reward-to-go, a learned baseline and GAE all reduce that noise. I measured each one.

<Clip src="/projects/rl/cs285-pg.png" alt="CS 285 policy-gradient learning curves on CartPole and HalfCheetah." caption="My CS 285 implementation. Vanilla REINFORCE on CartPole never settles. HalfCheetah with a learned baseline climbs from about -780 to 656." />

**CartPole.** Reward-to-go reached the maximum return of 200 at iteration 14. The full-trajectory return took 37.

<Clip src="/projects/rl/pg-cartpole-small-batch.png" alt="CartPole policy-gradient learning curves, batch size 1,500." caption="CartPole, batch 1,500." />

<Clip src="/projects/rl/pg-cartpole-large-batch.png" alt="CartPole policy-gradient learning curves, batch size 6,000." caption="CartPole, batch 6,000: the same estimators with 4× the samples per update." />

**InvertedPendulum.** A 25-run search over batch size and learning rate. A large batch reached the maximum return in 21 iterations. A small batch took 91 iterations but used fewer samples in total: 34.3k against 46.0k.

<Clip src="/projects/rl/pg-invpendulum-b2000.png" alt="InvertedPendulum learning curve, batch 2,000, learning rate 0.03." caption="Batch 2,000: maximum return at iteration 21, with oscillation." />

<Clip src="/projects/rl/pg-invpendulum-b300.png" alt="InvertedPendulum learning curve, batch 300, learning rate 0.01." caption="Batch 300: slower and noisier, but fewer total samples." />

**LunarLander.** The policy passed the target by iteration 41. It then collapsed after iteration 140 and recovered. One large step with a fixed learning rate can push a policy somewhere bad.

<Clip src="/projects/rl/pg-lunarlander.png" alt="LunarLander policy-gradient learning curve over 250 iterations." caption="LunarLander: target met, then a collapse and recovery." />

**HalfCheetah.** A 9-run search chose the settings. Then a 4-run ablation separated the tricks. Reward-to-go did almost all the work: 144.7 return against 35.4 without it. A learned baseline on its own made things worse.

<Clip src="/projects/rl/pg-halfcheetah-search.png" alt="HalfCheetah eval return for 9 batch-size and learning-rate combinations." caption="HalfCheetah search: learning rate mattered most." />

<Clip src="/projects/rl/pg-halfcheetah-ablation.png" alt="HalfCheetah ablation of reward-to-go and a learned baseline." caption="HalfCheetah ablation: plain, reward-to-go, baseline, and both." />

**Hopper.** I swept GAE's λ. At λ = 0 the policy never passed about 220, because it relied on an inaccurate value estimate. λ = 0.99 did best, at 528.

<Clip src="/projects/rl/pg-hopper-gae.png" alt="Hopper learning curves for GAE lambda 0, 0.95, 0.99 and 1." caption="Hopper: λ = 0 oscillates. λ near 1 keeps learning." />

**Paper: HORA** (Qi et al., CoRL 2022). A robot hand learns to rotate objects in simulation with PPO. It uses the same tools as above: a value baseline and GAE.

## 3. DQN and SAC

<Course>CS 285 · HW3</Course>

Value-based methods can overestimate. Their targets take a max over noisy estimates, and that max is biased upward. Target networks, double-Q and twin critics all keep this bias in check.

<Clip src="/projects/rl/cs285-dqn-cartpole.png" alt="DQN learning curve and mean predicted Q-value on CartPole." caption="DQN on CartPole: evaluation return peaked at 409, then settled near 100. Single seed." />

<Clip src="/projects/rl/cs285-sac.png" alt="SAC learning curves on HalfCheetah and InvertedPendulum, and the auto-tuned entropy temperature." caption="SAC from scratch. HalfCheetah eval return rises from -223 to 4,189. The entropy temperature tunes itself as the gait takes off." />

## What the curves taught me

A rising reward curve proves less than it looks. My HalfCheetah reaches about 4,200 return and really does run. But the number alone couldn't tell me that. On [my biped](/projects/bipedal-walker), a policy with healthy curves turned out to be standing still. Now I check a physical metric before I trust a curve.

*These are course implementations on single seeds. A rigorous comparison would use more seeds and confidence intervals.*
